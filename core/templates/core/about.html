{% include "components/heading.html" with level="h2" text="Get started" classes="text-dark" %}

Clone the starter, install its Python and Tailwind dependencies, then run Django and the CSS watcher in separate terminals.

# Replace my-project with your preferred folder name
git clone https://github.com/sjmitch-git/alpine-starter.git my-project
cd my-project
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py tailwind install
# In separate terminals, run:
npm run dev
npm run watch:css
